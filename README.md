## Breve Descripción del Proyecto
En esta tercera fase del proyecto se implementó el **modelo físico relacional** para la Red Social Estudiantil Pascualina a partir del modelo lógico diseñado en la Tarea 2. 

El sistema cuenta con un total de **15 tablas** que gestionan perfiles académicos, publicaciones, comentarios, grupos de estudio, eventos, intereses, habilidades, reacciones, red de seguidores y mentorías. La base de datos fue construida en **PostgreSQL**, aplicando restricciones de integridad referencial con borrado y actualización en cascada (`ON DELETE CASCADE`, `ON UPDATE CASCADE`).
